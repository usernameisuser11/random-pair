# 랜덤 짝 매칭

이전 대화에서 받은 105명 명단이 기본 입력되어 있는 간단한 GitHub Pages 정적 웹사이트입니다.

- 화면을 열면 105명 명단이 바로 표시됨
- 짝 만들기 / 다시 섞기
- 홀수 인원은 3인조 1개 구성 또는 1명 남기기
- 남녀 우선 매칭을 사용하려면 이름 뒤에 `, 남` 또는 `, 여` 추가
- 명단 교체, CSV/TXT 불러오기, 결과 복사, CSV 저장

## 배포

새 공개 GitHub 저장소에 `index.html`을 올리고 `Settings → Pages → Deploy from a branch → main / (root)`로 설정하세요.

**주의:** 명단이 HTML 안에 포함되므로, 이 상태로 공개 GitHub Pages에 배포하면 방문자와 저장소 열람자가 105명의 이름을 확인할 수 있습니다. 공개 배포 전 참가자들의 개인정보 공개 여부를 확인하세요.
